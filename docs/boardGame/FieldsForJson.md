### Описание полей JSON файла для действий предметов, статус эффектов и эффектов игрового поля

#### String type
Тип действия предмета

Примеры значени:
- applyStatusEffect - применить статус эффетк

Пример, применить статус эффект

`"type": "applyStatusEffect"`

#### Any value
Значение для применяемого эффекта

Пример, применить статус эффект (указываем slug статус эффекта, который должен быть применен)

`"value": "ya-sam-dobavil-eto-dermo"`

#### String target
Цель, на кого может применяться предмет

Примеры значени:
- current - текущйи игрок, то есть на себя
- oneOfAll - выбор любого игрока, включая текущего
- other - выбор любого игрока за исключением текущего
- all - на всех игроков
- allExpectMe - на всех игроков, за исключением текущего
- fromTo - ???
- notPlayBattleForPoints - игроки с которыми не текущий игрок не играл в битве за очки
- notInvitedToCoop - игроки с которыми не текущий игрок не имеет завершенных коопов
- nearestPlayer - ближайший к текущему игроку игрок
- noFurther_* - игрок, который находится не дельше чем * клекток от текущего игрока на игровом поле
- positionLeader - лидер на игровом поле


Пример, предмет применяется на текущего игрока, то есть на себя

`"target": "current"`

#### Boolean autoUse
Автоматическое применение предмета

Примеры значени:
- true - предмет будет применен автоматические, как попадет игроку в инвентарь из рулетки

`"autoUse": true`
