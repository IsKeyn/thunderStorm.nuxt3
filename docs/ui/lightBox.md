# Лайтбоксы

## LightBox.vue
### components/media/LightBox.vue

Компонент лайтболкса используется для просмотра и загрузки дополнительных данных о медия

### Пример вызова

    <img
            :src="getResizeImg(user.avatar)"
            :media-id="user.avatar.id"
            class="media-obj"
    >
    
Для вызова лайтбокса он должен быть подключен в используемом лейауте компонентом MediaById

    import MediaById from '@/components/media/MediaById.vue';
    <MediaById />

Для вызова лайтбокса элемент должен иметь атрибут media-id, media-id должен содержать id изображения с бекенда

Лайтбокс автоматические строит навигацию и показывает кнопки для следующего и\или предыдыдущего медиа объекта

Чтобы исключить элемент из навигации, необходимо добавить аттрибут
    
    :not-for-lb-nav="true"

Вы пожете использовать класс .media-obj, чтобы более явно указать использование лайтбокса на текущем элементе, а также наверить стили cursor="pointer"
