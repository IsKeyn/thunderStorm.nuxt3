# Кнопки в проекте

## ActionButton.vue
### components/layout/buttons/ActionButton.vue

Основаня используемая кнопка в проекте, позволяет отображать прелоадер при загрузке, содержимое кнопки может быть как название, так и полноценный slot

Содержит классы accept, denied для кнопок соглашения, отказа

```bash
import ActionButton from '@/components/layout/buttons/ActionButton.vue';

<ActionButton class="accept">Я простая кнопка</ActionButton>
```
